- Thiết kế CSDL.
- Xây dựng API Backend.
- Xử lý xác thực người dùng.
#### Chức năng phụ trách
- Đăng ký tài khoản.
- Đăng nhập, đăng xuất.
- Quản lý thông tin cá nhân.
- Thiết kế bảng Project, Task, Category, User.
- API CRUD dữ liệu.
