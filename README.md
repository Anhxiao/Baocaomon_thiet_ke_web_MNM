## Phân công nhiệm vụ
1. Thạch Nam Anh
- Phân tích: Khảo sát yêu cầu, đặc tả chức năng tài khoản và quản lý dự án.
- UML: Vẽ Use Case, Activity cho đăng ký, đăng nhập và quản lý tài khoản.
- CSDL: Thiết kế bảng Users và Categories.
- Backend: Xây dựng API đăng ký, đăng nhập, đăng xuất, cập nhật hồ sơ và quản lý danh mục.
- Frontend: Thiết kế giao diện đăng nhập, đăng ký, hồ sơ cá nhân và danh mục.
- Kiểm thử: Kiểm thử tài khoản, danh mục và chức năng xác thực.
2. Đỗ Thành Nhân
- Phân tích: Khảo sát yêu cầu, đặc tả chức năng quản lý dự án và Dashboard.
- UML: Vẽ Use Case, Activity cho tạo, sửa, xóa và theo dõi dự án.
- CSDL: Thiết kế bảng Projects và các quan hệ liên quan.
- Backend: Xây dựng API thêm, sửa, xóa, xem dự án và lấy dữ liệu Dashboard.
- Frontend: Thiết kế giao diện trang chủ, Dashboard, danh sách và chi tiết dự án.
- Kiểm thử: Kiểm thử quản lý dự án và hiển thị Dashboard.
3. Ngô Minh Mẫn
- Phân tích: Khảo sát yêu cầu, đặc tả chức năng quản lý công việc và thống kê.
- UML: Vẽ Use Case, Activity cho quản lý công việc và cập nhật trạng thái.
- CSDL: Thiết kế bảng Tasks và các quan hệ liên quan.
- Backend: Xây dựng API thêm, sửa, xóa công việc, cập nhật trạng thái, mức độ ưu tiên, hạn hoàn thành, tìm kiếm, lọc và thống kê.
- Frontend: Thiết kế giao diện quản lý công việc, tìm kiếm, lọc và biểu đồ thống kê.
- Kiểm thử: Kiểm thử quản lý công việc và thống kê tiến độ.
4. Phân công bổ sung và phối hợp
- Thạch Nam Anh: Tham gia xây dựng giao diện Dashboard và kiểm thử tích hợp.
- Đỗ Thành Nhân: Tham gia xây dựng chức năng lọc dự án và kiểm thử API.
- Ngô Minh Mẫn: Tham gia xây dựng giao diện chi tiết dự án và kiểm thử CSDL.
